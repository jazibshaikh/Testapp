flowchart TD
    Start[Visit GitHub repo] --> SignIn[Sign in or sign up with GitHub]
    SignIn --> UseTemplate[Click Use this template]
    UseTemplate --> Clone[Clone repo locally]
    Clone --> Install[Run npm install]
    Install --> Dev[Run npm run dev]
    Dev --> Home[Open browser at localhost:3000]
    Home --> About[Click About link]
    About --> Check[Click Check API Health]
    Check --> APIReq[Request to api health endpoint]
    APIReq --> OK[Receive success response]
    APIReq --> Fail[Receive error response]
    Dev --> Config[Edit .env and config files]
    Config --> Restart[Restart dev servers]
    Dev --> Error{Error state}
    Error --> Missing[Missing or invalid env variable]
    Error --> Conflict[Port conflict on 3000/4000]
    Missing --> FixEnv[Fix env and restart]
    Conflict --> FixPort[Modify port and restart]
